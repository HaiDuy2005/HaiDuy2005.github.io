# Hello, Duyverse!

Chào mừng bạn đến với **DUYVERSE** — không gian portfolio cá nhân nơi mình lưu trữ hành trình học tập, các dự án công nghệ thực tiễn và những thử nghiệm sáng tạo giữa lập trình và âm nhạc.

> *(Lưu ý: Đây là bài viết mẫu minh họa tính năng quản lý bài đăng bằng Markdown Content Collections trên Astro. Bạn có thể chỉnh sửa nội dung trong file `src/content/posts/hello-world.md`)*

## Vì sao mình xây dựng website này?

Là một sinh viên Công nghệ Thông tin, mình luôn mong muốn có một trang web mang đậm cá tính riêng:
1. **Một portfolio thực thụ**: Không dùng các template kéo thả có sẵn làm chậm web, mà tự xây dựng kiến trúc từ đầu bằng các công nghệ hiện đại.
2. **Quản lý nội dung thuận tiện**: Viết bài hoàn toàn bằng file Markdown (`.md`), hệ thống tự động sinh trang chi tiết, mục lục và phân loại tag mà không cần code HTML thủ công.
3. **Hiệu năng cao và tiết kiệm chi phí**: Triển khai hoàn toàn miễn phí trên GitHub Pages dưới dạng Static Site Generation (SSG), tốc độ tải trang cực nhanh và bảo mật tuyệt đối vì không dùng server backend phức tạp.

## Những nội dung sẽ được chia sẻ tại đây

Trong các bài viết tiếp theo, mình sẽ tập trung vào các nhóm chủ đề:

- **Lập trình Web & Frameworks**: Chia sẻ kinh nghiệm làm việc với Astro, React, ASP.NET Core, TypeScript và tối ưu giao diện responsive.
- **Cloud & Deployment**: Cách cấu hình CI/CD với GitHub Actions, hosting tĩnh và kiến trúc điện toán đám mây.
- **Trải nghiệm AI**: Áp dụng các mô hình ngôn ngữ lớn (LLM), Prompt Engineering và công cụ AI hỗ trợ lập trình viên.
- **Hip-hop & Creative Flow**: Những cảm hứng âm nhạc đằng sau quá trình tư duy logic.

## Lời kết

Website này là minh chứng cho quá trình học hỏi không ngừng. Cảm ơn bạn đã ghé thăm và theo dõi hành trình của mình!
